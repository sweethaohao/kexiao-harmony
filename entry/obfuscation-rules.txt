# ---------------------------------------------------------------------------
# 下面这些属性名**必须保留**，因为它们是外部 JSON 契约的字段名。
# 开了 -enable-property-obfuscation 后属性名会被改名，而 JSON.parse 出来的
# 对象键名仍是原文，按属性取值就会全部拿到 undefined —— 导入功能直接失效。
# 契约见 docs/03-数据模型.md「导入数据格式（JSON Schema v1）」
# ---------------------------------------------------------------------------
-keep-property-name
schemaVersion
source
courseCount
entries
courseName
courseCode
startSlot
endSlot
weeks
weeksRaw
campus
room
teacher
weekday
slot

# ---------------------------------------------------------------------------
# 作息参数也是同一个道理，但走的是另一条通道：
#   PeriodConfig[] 会序列化成 JSON 文本存进「首选项」（preferences），
#   读回来时 JSON.parse 得到的键名仍然是原文，而属性名会被混淆 ——
#   不保留的话，用户改过的作息在 release 包里读不出来，界面会悄悄退回默认值，
#   而且只在 release 包复现，最难查。
# 契约见 model/Models.ets 的 PeriodConfig。
# ---------------------------------------------------------------------------

key
label
startTime
bigCourseCount
smallPerBig
smallSlotMinutes
breakInBigMinutes
breakBetweenBigMinutes
trailingSmallCount
