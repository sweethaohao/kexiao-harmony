# tools/advanced —— 进阶导入工具（不随安装包分发）

这个目录里的东西**不会被打进 HAP**（hvigor 只编译 `entry/src/main/`），
它们是给「电脑侧的你自己」用的工具，用来把教务系统的课表变成课晓能吃的数据。

| 文件 | 干什么 | 门槛 |
|---|---|---|
| `kexiao-export.js` | 浏览器 Console 探针：捞 DOM 表格 + 列出 AJAX 接口 + 回读只读接口 | 要开开发者工具 |
| `parse_schedule.py` | 早期方案：把教务导出的 Word(.docx) 解析成课晓 JSON | 要电脑、要 Python |

> **先看下面第一节。** 这里的工具是**最后手段**。
> 如果你们**教务处官网**挂着公开的课表 `.xlsx`，课晓已经能**直接读**它
> （第一节 ①），根本不用开开发者工具。

---

## 一、先别急着开开发者工具，这四条路更省事

有些学校的教务系统把「复制」封死了：`Ctrl+A` 什么也选不中、鼠标拖也拖不出选区、
右键变灰、`F12` 被拦、甚至一开开发者工具就用 `debugger` 把页面挂起。

但**这些限制只挂在「复制这一步」上**，同一份数据往往还有别的形态。
按门槛从低到高试：

### ① 教务处官网的公开课表 `.xlsx` ★★ 优先试这个

**这条和教务系统无关，是绕过反复制最干净的一条，而且课晓已经内置了完整的导入支持。**

不少学校的**教务处官网**每学期会公开挂出「各校区课表 / 各教学班课表」的
`.xlsx` 附件 —— 它是教务处**自己从教务系统正式导出**的，格式比网页复制出来干净得多：
星期是独立的列，节次是独立的行，一门课的「课程名 / 周次 / 教室」分列可辨。

做法（实测可行，四步）：

1. 去教务处官网找「课表 / 教学安排 / 课表管理」栏目，下载本学期的附件（选你所在校区那份）
2. 课晓 →「导入课表」→「从文件导入」→ **把格式切到 `.xlsx`** → 选中那个文件
3. 课晓会把文件里**所有教学班**列出来 → 输入你的班号（如 `f250117`）筛出来 → 认领
4. 预览校对 → 确认导入

零门槛：**不用复制、不用电脑、不用脚本、不用开开发者工具。**

> 这份文件是整校区/整学院的，所以课晓做成了「先选班、再导入」。
> 如果你的学校也走这条路，把这份文件给课晓的开发者，就能针对它写精确的识别规则。

### ② 教务系统自己的「导出 Excel」

如果有这个按钮，导出的是**结构完整的表格文件**（星期是独立的列），比复制文本还好。
把导出的文件（`.xlsx` / `.csv`）直接丢进课晓的「从文件导入」。

### ③ 教务系统自己的「打印」窗口（⚠️ 实测有些学校也走不通）

课表页面上一般有个「打印」按钮，点开是**独立的打印预览页**，反复制的 CSS/JS
通常只挂在主页面、没跟过来 —— 所以**值得一试**。

> ⚠️ **但作者母校实测失败**：预览窗口里同样 `Ctrl+A` 不到，手动拖选 + `Ctrl+C`
> 复制出来的文本**仍然没有制表符**，和主页面是同一个病。
> 「独立页面」只保证反复制的脚本没跟过来，**不保证选区里会带表格结构**。
> 别在这上面耗太久。

### ④ 浏览器「查看网页源代码」

`Ctrl+U`（或右键 → 查看网页源代码），在新窗口里 `Ctrl+F` 搜一门课的名字：

- **搜到了** → 说明课表是服务端渲染的，源码里就是完整表格，直接全选复制存成文件
- **搜不到** → 说明是前端渲染的，走下面的 Console 探针

## 二、都不行时：`kexiao-export.js`

### 为什么这条路走得通

```
页面 DOM  ──►  脚本直接读  ──►  下载成文件  ──►  课晓「从文件导入」
```

它绕开的是 CSS 的 `user-select: none`、JS 的 `selectstart` / `copy` / `contextmenu`
拦截、以及 `debugger` 反调试 —— 这些**都只作用在「交互层」**。
浏览器最终必须把内容渲染出来给你看，**数据就一定在 DOM 里**。

> **边界（红线）**：只处理你自己登录后能看到的那一页。
> 不做自动登录、不做账号密码代填、不批量抓取学校服务器。

### 怎么用

**1. 打开课表页面**，把课表显示出来（该点的「查询」都点完，确认整张表都在）。

**2. 打开开发者工具。** `F12` 被拦时逐个试：

- `Ctrl + Shift + I`
- `Ctrl + Shift + J`（直接开 Console）
- 右键 → 检查
- 浏览器右上角 `⋮` → 更多工具 → 开发者工具

**页面卡住不动了**（`debugger` 生效）→ 切到 **Sources** 面板，点一下左上角的
**「停用断点」**（带斜杠的暂停符，Deactivate breakpoints，`Ctrl+F8`），页面立刻恢复。

**3. 跑脚本。** 切到 **Console** 面板（顶部若提示输入 `allow pasting`，照做）。
把 `kexiao-export.js` 的**全部内容**粘进去，回车。

**4. 拿结果。** 自动下载 **`kexiao-export.txt`**，放到 `G:\project\myP\data\` 下。

### 脚本做了三件事

| | 做什么 | 为什么重要 |
|---|---|---|
| **A** | 列出页面**已经请求过的**所有 AJAX 接口（读 `performance` 记录，不重新发请求） | 如果课表是接口返回的 JSON，这是最干净的数据源，比解析 DOM 稳得多 |
| **B** | 对「看起来是**只读**的接口」回读一次，把响应正文一起打包 | 写操作接口**一律跳过**（黑名单见源码里的 `MUTATING`），绝不会误触发选课/退课 |
| **C** | 扫描所有 `<table>`，按 `rowspan/colspan` 展开成网格；页面不是 table 布局时退化成「找含星期几的最大容器」并保留其 HTML | 覆盖服务端表格、前端表格、div 布局三种情况 |

### 输出文件里有什么

```
=== 课晓诊断 · 概览 ===              ← 地址、UA、表格/接口计数
=== AJAX 接口清单 ===                ← A 的结果
=== 页面尾部文字 ===                 ← 常能看出教务厂商（正方/强智/…）
=== 网格 #1 / #2 ===                 ← C 的结果，制表符分列，格内换行记作 ¶
=== 最能当课表用的那张表的 outerHTML ===
=== 接口回读 #1 ... ===              ← B 的结果
=== 页面快照 HTML ===                ← 写解析规则的原始材料
```

### 排错

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 没找到 `<table>`，但打印了「含星期的容器」 | 课表是 div 布局 | 正常，脚本已经把那个容器的 HTML 存下来了 |
| `<table>` 和含星期的容器都没有 | 课表在**跨域** iframe 里，或整页是 canvas 画的 | Console 左上角把执行上下文从 `top` 换成对应 frame；若确认是 canvas，改走 Network 面板找接口 |
| 行列数不对 | 挑错了表 | 看 Console 打印的表格清单，改脚本里 `tables.slice(0, 2)` 的序号 |
| 一开开发者工具就卡住 | 反调试 `debugger` | 按上面「停用断点」处理 |
| 下载被拦 | 浏览器拦截多文件下载 | 允许本次下载（脚本只下一次） |

## 三、这条路走到哪儿为止

`kexiao-export.js` 只是**第一步：把数据拿出来**。

拿到真实结构之后，课晓会针对这份结构写**精确的解析规则**，固化进 App 的解析器，
以后同校同学直接粘贴/导入就能用。

再往后是**分享**：一个同学导入成功后导出成一段分享文本，全班同学粘贴即可 ——
同一个教学班的课表本来就基本一样。

## 四、隐私

- `kexiao-export.txt` 里含**你的真实课表和学号**
- 只发给课晓的开发者用于写解析规则
- **绝不提交到任何公开仓库**（`.gitignore` 已覆盖 `data/`）
- 脚本本身不联网、不上传任何东西，全程在本地浏览器完成
