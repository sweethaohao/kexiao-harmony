# 课晓 · 需求与范围

> 版本：v0.1（草案）｜ 项目代号：kexiao（课晓）

## 1. 一句话定位

面向**鸿蒙 PC（2in1）**的**轻量校园日程助手**：把学生散落在各处的课程表、作业、待办整合到一个干净的应用里，并做**日程/闹钟提醒**。

## 2. 目标平台与约束

| 项 | 决定 |
|---|---|
| 系统 | HarmonyOS NEXT（纯鸿蒙） |
| 设备形态 | **2in1**（PC / 二合一，老师要求） |
| 技术栈 | ArkTS + ArkUI |
| 包名 | `com.sweethaohao.kexiao` |
| 开发工具 | DevEco Studio（最新稳定版） |
| 上架 | 华为应用市场（鸿蒙市场）个人开发者已实名 |
| 代码托管 | GitHub（作为课程作业提交） |
| 配套产出 | 一篇 CSDN 博客 |

## 3. 功能范围

### 3.1 MVP（第一版必做）✅

1. **课表导入**
   - 主路径：**应用内粘贴**——教务课表网页 `Ctrl+A/Ctrl+C`，或在 Excel 里选中课表区域复制，
     粘进「导入课表」页即可（剪贴板里本质都是「制表符分列 + 换行分行」的纯文本）
   - 兜底：**手动添加**单门课（教务系统太怪、或只有一两门课时用）
   - 降级：文件导入（`.json` 走课晓格式，`.txt`/`.csv` 走同一套文本解析）
   - 解析结果先进**预览校对态**，确认后才落库；演示用**示例课表**
   - 支持：连续周次、**并集周次（1~3,5~12周）**、单周/双周、单格多课、跨节次、含括号课程名
   - 另有一条**开发者自用**通道：`tools/advanced/parse_schedule.py`（电脑侧把教务 Word 转 JSON，
     不随包分发、不影响包体，见 `04-课表导入方案.md` §9）
2. **课表展示**
   - 周视图（星期一~星期日 × 节次）
   - 按**当前周次**高亮/过滤（第 N 周该上的课）
   - 课程卡片：名称、时间、地点、教师
3. **日程提醒 / 闹钟**
   - 基于 `Semester.startDate` 把"第 N 周星期 X 第 Y 节"换算成真实日期
   - 本地通知（提前 N 分钟）
4. **轻量侧边栏 UI**
   - 应用内可折叠侧栏（2in1 桌面式交互，非系统级悬浮窗）
5. **桌面服务卡片（万能卡片 / Form Kit）**
   - 展示"今日 / 近期日程"，打开即看

### 3.2 二期（后续）

- 作业整合：用户**粘贴作业网页链接** → 抓标题/截止时间 → 作为日程，点击跳转（雨课堂、知道等）
- 云同步（AGC 云开发）：PC ↔ 手机账号同步
- 手机端适配 + 手机桌面卡片
- 穿戴设备（手表）轻量展示

### 3.3 明确不做 / 做不到 ⚠️

- ❌ **不做**"直接读取其他 App 数据"（鸿蒙沙箱不允许，且违反 TOS）
- ❌ **不做**非官方爬取教务系统（合规风险，审核可能不过）
- ⚠️ **不做**系统级全局悬浮窗（普通上架应用拿不到该权限）—— 用"应用内侧边栏 + 桌面卡片"替代

## 4. 关键设计决策

| 决策点 | 结论 | 理由 |
|---|---|---|
| 数据来源 | 用户主动提供（docx / 手动 / 链接） | 合规、可上架 |
| docx 解析位置 | **放在电脑侧脚本**（非 App 内） | 避开鸿蒙端解压/XML 的复杂度，便于测试与写博客 |
| 悬浮窗形态 | 应用内侧边栏（非系统悬浮） | PC 权限限制 |
| 存储 | `relationalStore`（关系型） | 结构化数据、支持查询 |
| 同步 | 一期不做，二期上 AGC 云 | 先单端跑通 |
