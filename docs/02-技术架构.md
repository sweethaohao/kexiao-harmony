> 这条规矩换来的是：改完逻辑可以直接 `node tools/selftest/run.mjs` 在电脑上验证，

## 3. 关键技术选型（需在 DevEco 实测确认）

| 能力 | 方案 | 说明 |
|---|---|---|
| UI 框架 | ArkUI 声明式 | `@Entry @Component`，`@State` 驱动 |
| 存储（课表） | `@kit.ArkData` → `relationalStore` | ✅ 已落地：4 张表，导入走事务全量替换，启动即从库恢复 |
| 存储（配置） | `@kit.ArkData` → `preferences` | ✅ 已落地：作息参数与侧栏折叠。"一整块配置"适合键值对 |
| 文件读写 | `@ohos.file.fs` + 文件选择器 `@ohos.file.picker` | 读取用户选的 `.json` / `.txt` / `.csv`（降级通道） |
| 读取剪贴板 | **`PasteButton` 安全组件** | ✅ 已落地。API 12 起 `READ_PASTEBOARD` 是 system_basic 受限权限，普通应用声明无效；PasteButton 点一下即临时授权，无需申请权限。注意它**不支持 `.margin()`** |
| 本地通知 | `@ohos.notificationManager` | 日程提醒 |
| 后台任务 | `@ohos.resourceschedule.workScheduler` 或 reminderAgent | **闹钟/定时提醒**（需实测 2in1 支持） |
| 桌面卡片 | Form Kit（`FormExtensionAbility`） | "今日日程"卡片 |
| 窗口 | `@ohos.window` | 2in1 桌面窗口、侧栏布局 |

2. 桌面服务卡片在 2in1 的形态与刷新机制
3. 文件选择器在 PC 端的表现

## 4. 分层职责

- **ImportService**（纯逻辑）：读 JSON → 校验 schema → 调 `buildResult()` 归并 Course、汇总告警
- **TextImportService**（纯逻辑）：粘贴文本 → 三种形态识别 → 调同一个 `buildResult()`。
  两条上游（文件 / 粘贴）走完全相同的收口规则，避免"两套去重逻辑各写一遍"
- **ScheduleEditor**（纯逻辑）：手动增删改，`buildResult()` 打包成 `ImportResult`
  → 与导入共用 `saveImport()` 落库路径
- **ScheduleRepository**（存储入口，页面只认识它）：
  - `loadSnapshot()`：一次读齐学期设置 + 导入来源 + 全部课表项
  - `saveImport()`：事务内全量替换；学期起始日"库里已有就沿用、没有才按导入当周推算"
  - `updateSemesterStart()` / `clearAll()`
- **ScheduleDao**：SQL 执行与结果集搬运。读写一律走 `getColumnIndex(列名)` + 下标，
  避开 release 属性名混淆
- **SettingsStore**：首选项读写（作息参数、侧栏折叠），出错一律降级、不让应用崩
- **StorageMapper**（纯逻辑）：行记录 ↔ 领域模型互转、两张表拼装成 `ScheduleItem[]`
- **ScheduleService**（纯逻辑）：
  - `itemsOfWeek(items, n)`：取第 n 周的课（`weeks.includes(n)`）
  - `coursesOfDate(items, semester, date)`：按真实日期取课
  - `dateOfWeekday(semester, week, weekday)`：周次+星期 → 真实日期（依赖 `startDate` + `SlotTimeTable`）
  - `getDailyBrief(...)`：今明日程。今天的课全上完了，就自动切到后面最近有课的一天
- **ReminderService**（二期）：基于上面换算结果，注册通知/闹钟

## 5. 关于"侧边栏"与"2in1"

- 2in1 使用**桌面式窗口**（可拖拽/缩放），不像手机全屏。
- "QQ 式可隐藏侧边栏" → 实现为**应用内布局**：`Row { 侧栏(可折叠) + 主内容 }`，用状态变量控制侧栏宽度动画。
- 系统级全局悬浮窗（跨应用常驻）在普通上架应用上**通常不可行**，故不采用。

## 6. 合规与上架提醒

- 不抓取、不读取第三方 App 数据；数据均由用户主动提供。
- 隐私政策需声明：仅本地存储课表数据（一期无网络上传）。
- 应用名称"课晓"需在 AGC 创建时确认**未被占用**；包名 `com.sweethaohao.kexiao` 作为兜底唯一标识。
